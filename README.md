# Система массового обслуживания с механизмом распаковки заявок

**CMake**: version 3.5
\
**C++**: 17
\
**Qt**: 3.5/3.6

## Текущее состояние проекта

Была переопределен основной цикл моделирования MainSystem::RunImmitation. Теперь во время наступления события времена обслуживания заявок уменьшаются.
\
Также была добавлена возможность задать **параметр μ** для каждой фазы в отдельности. Для этого необходимо явно указать количество фаз в строке **device_num**, после чего нажать кнопку **Phases Settings**
\
В данный момент СМО поддерживает только единый вариант распределений. **<u>На текущий момент требуются уточнения от руководителя о математике выходных данных проекта</u>**
